## Информация

> На закрытом портале запустили «непроходимую» аркаду **Minesweeper Pro**: чтобы забрать главный приз, нужно разминировать **50 полей 9×9 подряд**, укладываясь в **25 секунд** на каждое. Ошибка или таймаут сбрасывают весь прогресс.

## Описание

Веб-задание на уязвимость доверия клиентским данным (Client-Side Trust). Сервис предлагает пройти 50 раундов сапёра 9×9 по 25 секунд, однако синхронизация прогресса вынесена в клиентский JS (`POST /api/score`), где сервер принимает количество побед без проверки.

## Решение

1. Открываем веб-интерфейс и смотрим исходный код страницы (`index.html`) или вкладку Network в DevTools.
2. После создания сессии (`POST /api/session`) клиент синхронизирует счёт через `POST /api/score` с JSON `{"wins": N}`, а при `flag_unlocked: true` забирает флаг с `GET /api/flag`.
3. Отправляем `POST /api/score` с `{"wins": 50}` (с полученной cookie `sid`) и делаем `GET /api/flag` — сервер отдаёт флаг. *(Альтернативно можно честно пройти 50 досок автопилотом через `POST /api/open` — флаг также вернётся в ответе на 50-й доске.)*
