# Чёрный ящик | Medium | reverse

## Информация

> Вам дан crackme — исполняемый файл для Linux x86-64. Он принимает ключ аргументом командной строки: ./crackme <ключ>. Найдите ключ, при котором программа выводит ACCESS GRANTED. Правильный ключ — флаг.
>
> Формат флага: `tomskfsp{...}`

## Деплой

Не требуется. Задание решается локально по выданным файлам.

Пересборка материалов автором из директории задания:

```sh
python3 src/generate.py
```

Для сборки нужны GCC и Linux x86-64.

## Выдать участникам

Архив содержимого директории [public/](public/). Сервер и строка подключения не требуются.

## Описание

Задание на анализ проверки ключа в исполняемом файле.

## Решение

Найти четыре 64-битные константы в main, восстановить их байты в little-endian и применить XOR с 0xd2. Удалить завершающий нулевой байт. Проверить результат запуском crackme с полученным флагом.
