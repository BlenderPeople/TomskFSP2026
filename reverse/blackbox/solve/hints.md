# Подсказки — 06. Чёрный ящик

## Подсказка 1 (мягкая)

`strings` и поиск по `.rodata` тут ничего не дадут — строка пришита в код.
Загрузите бинарник на dogbolt.org и посмотрите псевдокод `main`: там будут
присваивания `*(undefined8 *)(buf + ...) = 0x...` и цикл с XOR-ключом.
Константы + ключ — всё, что нужно для CyberChef.

## Подсказка 2 (сильная)

Рецепт CyberChef целиком:

1. склейте четыре 16-значных значения из псевдокода (после `0x`) в одну строку;
2. `Find / Replace`: `0x` → пусто (если остались);
3. `From Hex`, Delimiter: None;
4. `Swap Endianness`, Word length: **8** — байты в константе «перевёрнуты»
   (little-endian);
5. `XOR`, Key: `d2` (ключ читается в цикле декомпилированного `main`).

На выходе — флаг; после `}` будет завершающий `\x00`, это терминатор строки.
Проверка: `./crackme 'tomskfsp{...}'` → `ACCESS GRANTED`. Альтернатива
в терминале: `objdump -d crackme | grep movabs` покажет те же константы,
динамически — `ltrace ./crackme test` (strcmp увидит расшифрованную строку).
