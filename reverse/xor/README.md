## Информация

> Нам достался небольшой исполняемый файл без исходников. По слухам, разработчик зашил в него секретную строку и не стал полагаться на внешний сервер. Достаньте то, что скрыто внутри.
>
> Формат флага: `tomskfsp{...}`

## Выдать участникам

Архив из директории [public/](public/)

## Описание

Базовое reverse-задание на анализ скомпилированного ELF-файла `hidden_flag`. Зашифрованный массив байтов флага хранится в секции данных, каждый байт подвергнут операции XOR с константой `0x42`.

## Решение

1. Открываем `hidden_flag` в дизассемблере (или `objdump`/`readelf`) и находим массив `secret[]` в секции `.rodata`/`.data`.
2. Применяем XOR с ключом `0x42` к каждому байту массива и получаем флаг.
