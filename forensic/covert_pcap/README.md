# Тихий канал | Hard | forensic

## Информация

> Система мониторинга не фиксирует аномалий: сетевой обмен выглядит совершенно штатно. Но аналитик уверен, что один из узлов незаметно выводит данные наружу. Изучите перехваченный дамп и восстановите сообщение.
>
> Формат флага: `tomskfsp{...}`

## Выдать участникам

Архив из директории [public/](public/)

## Описание

Задание по сетевой криминалистике (анализ `capture.pcap`, около 900 пакетов). Один и тот же флаг передаётся тремя независимыми скрытыми каналами от узла `10.66.13.37` (DNS-поддомены, поля ICMP и исходные порты TCP SYN) на фоне обычного шумового трафика подсети `192.168.1.0/24`.

## Решение

1. Фильтруем трафик по адресу источника `ip.src == 10.66.13.37`.
2. Извлекаем данные из любого из трёх каналов:
   - **DNS**: запросы к `c<idx>.<hex-чанк>.exfil.example.com`;
   - **ICMP**: поля `id = (idx << 8) | byte1`, `seq = byte2`;
   - **TCP SYN (порт 443)**: `sport = (byte << 8) | idx`.
3. Сортируем фрагменты по `idx` и собираем исходный флаг.
