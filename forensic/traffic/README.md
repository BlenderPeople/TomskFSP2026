# Захват трафика | Medium | forensic

## Информация

> Студент Василий сохранил дамп traffic.pcap. Найдите флаг, оставленный в HTML-коде страницы расписания /faculties/fb сайта timetable.tusur.ru. В дампе есть ложные флаги в других ответах, служебных полях и посторонних каналах.
>
> Формат флага: `tomskfsp{...}`

## Деплой

Не требуется. Задание решается локально по выданным файлам.

Для скрипта решения нужен Scapy: `python3 -m pip install -r solve/requirements.txt`. Генератор дампа в комплект не входит.

## Выдать участникам

Архив содержимого директории [public/](public/). Сервер и строка подключения не требуются.

## Описание

Задание на исследование сетевого дампа и сопоставление данных с контекстом HTTP-обмена.

## Решение

Найти GET /faculties/fb и восстановить TCP-поток. Настоящий флаг находится в HTML-комментарии deploy note в ответе 200 OK. Остальные семь кандидатов — приманки.

[Подробное решение](solve/writeup.md).
[Скрипт решения](solve/solve.py). Запуск из директории задания: `python3 solve/solve.py`.
