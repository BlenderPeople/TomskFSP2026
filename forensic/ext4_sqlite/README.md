## Информация

> Перед проверкой сотрудник успел навести порядок на рабочей станции и удалить всё лишнее. Нам достался лишь образ диска. Проверьте, действительно ли секретные данные исчезли без следа.
>
> Формат флага: `tomskfsp{...}`

## Выдать участникам

Архив из директории [public/](public/)

## Описание

Форензик-задание по анализу образа диска `disk.img` (ext4, 32 МБ). В каталоге `/home/analyst/` находятся журнал `notes.txt` и база SQLite `app.db` с журналом транзакций `app.db-wal`. Флаг присутствует в неконтролированном WAL-журнале и в неразмеченных блоках удалённого файла `deleted_secret.txt`.

## Решение

1. Открываем образ без монтирования с помощью `debugfs` или `sleuthkit` и выгружаем `/home/analyst/app.db-wal`.
2. Ищем строку формата `tomskfsp{...}` в выгруженном WAL-файле (`strings app.db-wal | grep tomskfsp`) либо напрямую в образе `disk.img`.
