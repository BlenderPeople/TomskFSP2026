## Информация

> На внутреннем узле перехватили фрагмент сетевого обмена корпоративного портала. Администратор уверен, что ничего важного в дамп не попало. Проверьте так ли это.
>
> Формат флага: `tomskfsp{...}`

## Выдать участникам

Архив из директории [public/](public/)

## Описание

Форензик-задание на анализ сетевого дампа `http_auth_challenge.pcap`. В дампе содержится незашифрованный HTTP POST-запрос на `/login.php` с учётными данными и ответом сервера, содержащим флаг.

## Решение

1. Открываем `http_auth_challenge.pcap` в Wireshark (или разбираем скриптом).
2. Находим HTTP-запрос `POST /login.php` и делаем **Follow TCP Stream**.
3. В теле ответа сервера находим флаг.

[Эксплоит](solve/solve.py)

`tomskfsp{http_auth_leaked}`
