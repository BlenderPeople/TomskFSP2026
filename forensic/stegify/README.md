# Следы на флешке | Hard | forensic

## Информация

> При осмотре рабочего места изъяли образ съёмного носителя. На первый взгляд там обычные пользовательские каталоги с документами и фотографиями, но самое интересное надёжно закрыто. Найдите способ добраться до содержимого.
>
> Формат флага: `tomskfsp{...}`

## Выдать участникам

Архив из директории [public/](public/)

## Описание

Комплексное задание (Forensic + Stego) на анализ образа файловой системы ext4 (`forensic_image.dd`). Внутри образа находятся каталоги `Documents`, `Pictures`, `Downloads`: в `Pictures` лежит изображение с паролем, скрытым через `steghide`, а в `Documents` — запароленный архив `flag.zip` с файлом `secret.txt`.

## Решение

1. Исследуем `forensic_image.dd` через `debugfs` / `fls` (или монтируем образ) и извлекаем картинку из `Pictures/` и `flag.zip` из `Documents/`.
2. Извлекаем пароль из изображения с помощью `steghide extract -sf <image> -p "123"`.
3. Распаковываем `flag.zip` полученным паролем и читаем `secret.txt` с флагом.
