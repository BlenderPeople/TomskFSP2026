# Скрытый отчёт | Easy | misc

## Информация

> В отчёте lab6.pdf скрыт флаг. Исследуйте документ и найдите его.
>
> Формат флага: `tomskfsp{...}`

## Деплой

Не требуется. Задание решается локально по выданным файлам.

Исходный документ: [src/lab6.docx](src/lab6.docx). При смене флага обновить DOCX, экспортировать PDF и проверить извлечение текста. Для скрипта решения нужен Poppler (`pdftotext`).

## Выдать участникам

Архив содержимого директории [public/](public/). Сервер и строка подключения не требуются.

## Описание

Задание на исследование текстового слоя PDF-документа.

## Решение

На третьей странице флаг закрыт чёрным выделением, но остаётся в текстовом слое. Скопировать текст или выполнить pdftotext lab6.pdf - и найти tomskfsp{...}.

[Подробное решение](solve/writeup.md).
[Скрипт решения](solve/solve.py). Запуск из директории задания: `python3 solve/solve.py`.

## Флаг

`tomskfsp{pdf_text_unsave}`
