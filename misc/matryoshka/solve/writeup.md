# Матрёшка

## Суть задачи

Строка в `message.txt` упакована в три слоя кодирования. У каждого слоя свой
узнаваемый алфавит, поэтому порядок распаковки определяется на глаз:

| Слой (снаружи внутрь) | Алфавит-маркер |
|---|---|
| base64 | `A-Za-z0-9+/=`, смешанный регистр |
| base32 | `A-Z2-7=`, только верхний регистр |
| hex | `0-9a-f` (в данном случае — только цифры и `a-f`) |

## Решение

### Шаг 1: распаковка всех слоёв

```python
import base64

data = open("message.txt").read().strip()

layer2 = base64.b64decode(data).decode()      # снимаем base64 -> получаем base32
layer1 = base64.b32decode(layer2).decode()    # снимаем base32 -> получаем hex
flag   = bytes.fromhex(layer1).decode()       # hex -> исходная строка
print(flag)
```

### Эквивалент в утилитах Linux

```bash
cat message.txt | base64 -d | base32 -d | xxd -r -p
```

> **Флаг:** `tomskfsp{m4tr0shk4_3nc0d1ng}`

## Вывод для студентов

Кодирование — это **не** шифрование: никаких секретов base64 не хранит, любой
слой снимается без ключа. Умение узнавать кодировки по алфавиту — базовый
навык триажа любых CTF-задач.
