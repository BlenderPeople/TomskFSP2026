# Подсказки — 01. Матрёшка

## Подсказка 1 (мягкая)

Посмотрите на алфавит строки в `message.txt`: смешанный регистр и `+/=` на конце —
это base64. Раскройте его и посмотрите, что получится дальше.

## Подсказка 2 (сильная)

После base64 получится строка только из заглавных букв и цифр 2–7 — это base32.
После base32 — шестнадцатеричная строка: `xxd -r -p` (или `bytes.fromhex()`)
превратит её в текст. Цепочка целиком:

```bash
cat message.txt | base64 -d | base32 -d | xxd -r -p
```
