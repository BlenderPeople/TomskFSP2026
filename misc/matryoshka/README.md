# Матрёшка | Easy | misc

## Информация

> Староста получил странную строку в message.txt: кажется, её упаковали несколько раз. Каждый слой — один из стандартных способов кодирования. Разберите слои и найдите спрятанный флаг.
>
> Формат флага: `tomskfsp{...}`

## Деплой

Не требуется. Задание решается локально по выданным файлам.

Пересборка материалов автором из директории задания:

```sh
python3 src/generate.py
```

## Выдать участникам

Архив содержимого директории [public/](public/). Сервер и строка подключения не требуются.

## Описание

Задание на распознавание распространённых форматов кодирования данных.

## Решение

Последовательно декодировать Base64, Base32 и hex. Полученная строка содержит флаг.

[Подробное решение](solve/writeup.md).
[Скрипт решения](solve/solve.py). Запуск из директории задания: `python3 solve/solve.py`.
