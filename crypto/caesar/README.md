# Старая записка | Easy | crypto

## Информация

> В архиве переписки нашли обрывок служебной записки. На первый взгляд — бессмысленный набор букв, но автор явно не стал усложнять защиту и обошёлся простым сдвигом.
>
> Формат флага: `tomskfsp{...}`

## Выдать участникам

Архив из директории [public/](public/)

## Описание

Базовая криптографическая задача на шифр Цезаря. В файле `cipher.txt` зашифрована строка флага сдвигом на 19 позиций по строчному латинскому алфавиту (прочие символы не изменены).

## Решение

1. Читаем содержимое `cipher.txt`.
2. Применяем обратный сдвиг Цезаря на 19 позиций (или перебираем все 25 сдвигов).
3. Получаем флаг `tomskfsp{caesar_n1net33n_shift}`.
