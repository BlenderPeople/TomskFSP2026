# Экономия на безопасности | Easy | crypto

## Информация

> Разработчик защитил личную заметку одной операцией с секретным байтом. В резервной копии остался только Hex-дамп note.hex. Восстановите заметку.
>
> Формат флага: `tomskfsp{...}`

## Деплой

Не требуется. Задание решается локально по выданным файлам.

Пересборка материалов автором из директории задания:

```sh
python3 src/build.py
```

## Выдать участникам

Архив содержимого директории [public/](public/). Сервер и строка подключения не требуются.

## Описание

Задание на восстановление текста, защищённого коротким ключом.

## Решение

Декодировать Hex и перебрать однобайтовые XOR-ключи. Ключ 0xa7 восстанавливает заметку с флагом.

[Подробное решение](solve/writeup.md).
[Скрипт решения](solve/solve.py). Запуск из директории задания: `python3 solve/solve.py`.

## Флаг

`tomskfsp{one_byte_is_not_a_secret}`
