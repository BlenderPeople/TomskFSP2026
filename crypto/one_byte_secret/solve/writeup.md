# Экономия на безопасности — авторское решение

Флаг: `tomskfsp{one_byte_is_not_a_secret}`.

## Решение без кода

1. Открыть https://gchq.github.io/CyberChef/.
2. В Input вставить содержимое note.hex.
3. Добавить **From Hex**, затем **XOR Brute Force**.
4. Выбрать длину ключа 1 байт (обычно значение по умолчанию).
5. Найти читаемую строку с PRIVATE NOTE и флагом. Ключ — `a7` в Hex.

Для проверки убрать перебор и применить **XOR**, Key = `a7`, формат Hex.
Нужен именно байт A7, а не два ASCII-символа a и 7.
