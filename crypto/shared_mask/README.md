# Один фильтр на двоих | Medium | crypto

## Информация

> Фотограф обработал два изображения самодельным «защитным фильтром». Чтобы не хранить лишние файлы, одну маску использовали дважды. Восстановите скрытую надпись.
>
> Формат флага: `tomskfsp{...}`

## Деплой

Не требуется. Задание решается локально по выданным файлам.

Пересборка материалов автором из директории задания:

```sh
python3 src/build.py
```

Для сборки и скрипта решения нужен Pillow: `python3 -m pip install -r src/requirements.txt`.

## Выдать участникам

Архив содержимого директории [public/](public/). Сервер и строка подключения не требуются.

## Описание

Задание о последствиях повторного использования маски для защиты изображений.

## Решение

Выполнить XOR RGB-пикселей frame-a.png и frame-b.png. Общая маска сокращается, на результате видна надпись с флагом.

[Подробное решение](solve/writeup.md).
[Скрипт решения](solve/solve.py). Запуск из директории задания: `python3 solve/solve.py`.
