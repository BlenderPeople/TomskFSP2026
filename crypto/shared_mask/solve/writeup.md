# Один фильтр на двоих — авторское решение

Флаг: `tomskfsp{v1sual_x0r_explanat10n}`.

## Решение штатным инструментом, без скриптов

Из каталога с распакованными PNG выполнить одну команду ImageMagick:

```sh
convert frame-a.png frame-b.png -evaluate-sequence Xor result.png
```

На ImageMagick 7 имя команды — magick:

```sh
magick frame-a.png frame-b.png -evaluate-sequence Xor result.png
```

Открыть result.png в просмотрщике изображений. На нём виден флаг.
ImageMagick доступен в Kali как пакет imagemagick; перед турниром
проверить, что он установлен на предоставленном образе.
Команда проверена на ImageMagick 7.1.2-35: результат побайтно по RGB
совпадает с solve/expected-result.png.

## Почему это работает

C1 = P1 XOR M, C2 = P2 XOR M. Поэтому C1 XOR C2 = P1 XOR P2.
Исходники специально подготовлены: в области надписи первая картинка
чёрная, и текст второй остаётся читаемым. Маска случайная и одинакова для
обоих изображений. XOR сжатых файлов PNG не заменяет XOR RGB-пикселей.

При пересборке меняется маска, но итоговая надпись остаётся прежней.
Образец результата находится только в solve/, вне выдаваемого ZIP.
Исходная идея: Lemur XOR, https://cryptohack.org/challenges/general/.

## Смена флага

Изменить константу FLAG в `src/build.py` и выполнить `python3 src/build.py`.
Сборщик адаптирует размер шрифта под длину флага, создаёт оба PNG,
контрольный результат. После изменения визуально проверить
надпись и заново собрать архив из public/ и обновить статический флаг на платформе.
